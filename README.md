# Portfolio Rizky Sefiana

Website portfolio statis menggunakan HTML, CSS, dan JavaScript.

## Cara menjalankan
1. Ekstrak file ZIP.
2. Buka folder `rizky_sefiana_portfolio` di Visual Studio Code.
3. Buka `index.html` di browser, atau gunakan ekstensi Live Server di VS Code.

## Sebelum dipublikasikan
- Ganti `your.email@example.com` pada `index.html` dengan email aktif.
- Tambahkan tautan LinkedIn/GitHub jika sudah siap.
- Ganti ilustrasi proyek dengan screenshot asli ketika tersedia.
- Lengkapi kontribusi dan teknologi Paradiglaw setelah detailnya dipastikan.

Ilustrasi pada kartu proyek saat ini hanya visual placeholder, bukan screenshot hasil proyek asli.
